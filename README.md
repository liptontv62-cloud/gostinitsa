# HOTEL — информационная система гостиницы

Веб-приложение для управления номерным фондом и бронированиями.

## Возможности
- Авторизация и разграничение прав доступа.
- Просмотр номеров, создание, поиск, редактирование и отмена бронирований.
- Проверка вместимости и пересечения дат, расчёт стоимости проживания.

## Технологии
PHP 8.2+, MySQL 8 / MariaDB, HTML, CSS, JavaScript. Корневой каталог веб-сервера — `public/`.

## Установка через Open Server Panel
1. Клонируйте репозиторий и откройте его в Visual Studio Code.
2. Включите PHP с расширением `pdo_mysql` и MySQL/MariaDB. Настройте локальный домен с корневым каталогом `public/`.
3. Импортируйте `database/mysql.sql` в SQL-клиенте.
4. Скопируйте `config.example.php` в `config.local.php` и укажите параметры подключения к БД.
5. Выполните `php tools/init-users.php` в терминале с PHP из панели.
6. Откройте локальный домен в браузере.

Демонстрационные учётные записи: `admin / HotelAdmin!26`, `viewer / HotelViewer!26`. Для эксплуатации замените пароли и создайте отдельного пользователя БД с минимальными необходимыми правами.

## Работа с приложением
Войдите в систему, откройте раздел «Бронирования», заполните форму и сохраните запись. Поиск, редактирование и отмена доступны в журнале. При отмене запись сохраняется со статусом «Отменена». Роль viewer имеет доступ только к просмотру.

## Тестирование
Ветка `main` содержит исправленную версию, `module-2` — версию с тремя контролируемыми дефектами интерфейса по заданию МДК 05.02. Автоматизированные проверки находятся в `tools/test-http.py`. Проверки в Linux выполнялись с SQLite; развёртывание через Open Server Panel с MySQL проверяется отдельно.

Для локального тестового запуска:
```sh
python3 tools/init-sqlite.py /tmp/hotel.sqlite
HOTEL_TEST_SQLITE=/tmp/hotel.sqlite php -d ffi.enable=true tools/init-users.php
HOTEL_TEST_SQLITE=/tmp/hotel.sqlite php -d ffi.enable=true -S 127.0.0.1:8080 -t public
```
При наличии PDO SQLite FFI не требуется. Тестовый адаптер не используется при развёртывании MySQL.
